# UX Profile

Generated by `setup-ui-ux-skills`. All UI/UX skills in this project read this file before changing layout, copy, or interaction.

## Aesthetic reference

- **Standard:** Apple Native
- **Notes:** Espacios generosos, objetivos táctiles amplios, radios unificados, separadores suaves y transiciones cortas con propósito. Marca Cumplido (dos productos: Cumplido Salud y Cumplido Belleza). Colores de la especificación: azul institucional #0B4A91, azul profundo #073B78, azul claro #EAF4FF, turquesa salud #00A887, rosa belleza #D91B83, violeta administración #6339C8, fondo #F4F7FB, texto #172B4D, bordes #D9E2EF. Tipografía Inter, escala de espaciado de 4 px, tema claro y oscuro. Tokens en `src/styles/global.css`. Pendiente de alinear con el estándar: hoy conviven radios de 6, 10, 16 y 24 px; unificarlos en una escala más corta.

## Banned anti-aesthetics

- Glassmorphism / `backdrop-filter` sin un borde de alto contraste
- Píldoras pastel flotantes para metadatos comunes
- Degradados decorativos arbitrarios y bordes de neón brillantes
- Degradados radiales arcoíris multicolor en botones de acción
- Ilustraciones de caricatura en estados vacíos (personas saludando o chocando manos)
- Barras de scroll anidadas y exceso de iconos dentro de los campos

## Accessibility target

- **Level:** WCAG 2.1 AA
- **Contrast:** 4.5:1 para texto normal; 3:1 para texto grande, bordes de controles e iconos con significado. Usar las variantes `--c-health-ink`, `--c-beauty-ink` y `--c-admin-ink` cuando el turquesa, el rosa o el violeta van en texto.
- **Touch / focus:** Objetivos táctiles de 44×44 px como mínimo; anillo de foco visible (`:focus-visible`, 3 px). Respetar `prefers-reduced-motion`.

## Brand tone and microcopy voice

- **Voice:** Warm & Humancentric
- **Capitalization:** Sentence case for UI copy and buttons
- **Notes:** Español de Colombia, tuteo. Le hablamos a dueños y equipos de consultorios y salones, sin jerga técnica. Nombrar las cosas como las dice el usuario (pacientes en Salud, clientes en Belleza). Botones que dicen exactamente lo que pasa ("Pedir demo de Cumplido Salud", no "Enviar"). Honestidad sobre el estado del producto: nunca presentar como disponible lo que está en desarrollo; no inventar cifras, testimonios ni certificaciones.

## Icon library

- **Library:** Lucide
- **Package / path:** `lucide-static`, renderizado en el servidor por `src/components/Icon.astro`
- **Notes:** Única excepción: el icono propio `Tooth` (diente) definido en `Icon.astro` con el mismo trazo de 2 px y estilo Lucide. Cualquier icono nuevo que falte se dibuja así, en ese archivo.

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. Prefer skills by task: new page → `page-patterns` (name the pattern before markup); layout / chrome → `viewports`; forms → `forms`; overlays → `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only the recorded icon library (or project SVG path). Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit confirmation dialog.
